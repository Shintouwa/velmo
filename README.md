# Velmo

> Fast, private, universal any-to-any document and image converter.

🚀 **Live App:** [https://velmo.onrender.com](https://velmo.onrender.com)

---

### Supported Formats (11 Formats Any-to-Any)

| Category | Formats |
| :--- | :--- |
| **Documents** | **PDF** (`.pdf`), **Word** (`.docx`), **PowerPoint** (`.pptx`) |
| **Data** | **Excel** (`.xlsx`), **CSV** (`.csv`) |
| **Images** | **PNG** (`.png`), **JPG** (`.jpg`), **WebP** (`.webp`) |
| **Text & Web** | **Markdown** (`.md`), **Plain Text** (`.txt`), **HTML** (`.html`) |

---

### Core Features

- **Any-to-Any Universal Conversion:** Seamlessly convert between any supported document, spreadsheet, presentation, image, or text format.
- **In-Browser Editable Preview:** Inspect OCR output, edit text or spreadsheet cells in an interactive grid, and export directly to your chosen format.
- **Mixed-Format Batch Conversion:** Upload and convert multiple files across different formats simultaneously into a single, clean ZIP download.
- **Local On-Device OCR:** Automatically extracts text and tabular structures from images and scanned documents without relying on external cloud APIs.
- **Free & Unlimited with No Login:** Fully unrestricted conversions with zero file size limits, no tracking, and no account required.
